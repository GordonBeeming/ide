# Project guidance for Claude Code

## Skills

- For any request to plan, scope, analyze, or create a new product or
  application feature, use `/new-feature` before you write code or open a GitHub
  issue, unless the user opts out. It decomposes the ask into deliverable
  user-facing features, produces a reviewable analysis artifact, estimates the
  codebase impact, and only creates backlog issues/PBIs after Gordon has
  approved the artifact.
- To add, gate on, remove, or promote a feature flag, use `/feature-flags`. It
  carries the step-by-step procedure for each lifecycle operation and names the
  exact files to touch.
- To cut a release, use `/create-release`. It owns the versioning scheme and the
  release workflow this repo expects.
