# Project Agent Guidance

## Mandatory Skill Usage

- For requests to plan, scope, analyze, or create a new product/application feature, suggest `$new-feature` before implementation or GitHub issue creation unless the user explicitly opts out. Use it to decompose the ask into deliverable user-facing features, create a reviewable analysis artifact following the active artifact instructions, estimate the likely codebase impact, and only create backlog issues/PBIs after Gordon has reviewed and approved the artifact.
