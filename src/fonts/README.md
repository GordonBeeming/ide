# Self-hosted fonts

Space Grotesk (400/600/700) and IBM Plex Mono (400/500/600), latin subset only,
downloaded from Google Fonts (`fonts.googleapis.com/css2`) and self-hosted here
so the app never fetches from a font CDN at runtime.

Both typefaces are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/):

- Space Grotesk — Copyright 2019 The Space Grotesk Project Authors.
- IBM Plex Mono — Copyright 2017 IBM Corp.

The OFL permits bundling, self-hosting, and redistribution as part of this
application.
